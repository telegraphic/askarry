Sensitivity Verification

This page checks a sample of them. It sends each figure's stated parameters to SKAO's live sensitivity-calculator API. This is a real network call to the same backend astronomers use, not a document search. The result shows which quoted numbers still hold up.

Scope & method

This page selects twelve entries from the instrument-requirements ledger. Each entry states enough parameters, such as band, integration time, and bandwidth, to attempt a fair recalculation. For each entry, this page re-locates the source sentence in the corpus. It then calls query_sensitivity_calc against SKAO's real sensitivity-calculator API, using the paper's own stated parameters wherever possible. A verdict of diverges or matches requires a parameter set justified directly by the paper's text. Without that justification, the entry is marked not independently verifiable. This page does not force a comparison the source text cannot support.

A capability quirk surfaced in the process: Band 5a/5b calculator calls require the "(15-m antennas only)" subarray label. The live API rejects the plain AA*/AA4 labels for those bands. This confirms that Band 5a/5b is scoped to the 80-of-144-dish subset in practice, not only in the science literature. See Part IX, Capability Cross-Check, for more on this.

The misattribution

C-07 traces to the wrong paper, band, and science case

The ledger lists figures for "starless-core synchrotron/polarization": σ_I = 12.6 µJy/bm and σ_Q,U = 0.24 µJy/bm at 50 hours. This page re-located those figures verbatim, but in a different chapter. The figures belong to Vacca et al.'s statistical-methods paper on rotation-measure grids in galaxy clusters. That paper describes SKA-Mid AA4 Band 2 (0.95–1.67 GHz) at 17″ resolution for cluster diffuse polarization. The ledger's row (C-07) instead cites Bracco et al. and describes SKA-Low at 74–350 MHz for starless molecular cores. Bracco et al.'s own paper does discuss SKA-Low core-detection integration times. For example, it gives under 100 hours with AA* and under 50 hours with AA4, for a single Orion-like core at 200–300 MHz. It does not contain the σ_I/σ_Q,U figures of 12.6 and 0.24 µJy anywhere. This points to a citation swap introduced during the original requirements-ledger pass. It is not a live-calculator disagreement. It needs a manual fix in Part II·C.

Reading the verdicts: A match means the live calculator reproduced the paper's figure to within roughly 10%, using parameters drawn directly from the paper's own text. A divergence means a real gap remained even after a good-faith parameter match. In both divergence cases found here, C-09 and D-02, the gap traces to a beam-size or resolution target that implies an unstated weighting or taper choice. Neither source contains an error. Not independently verifiable applies whenever the source text does not state enough of frequency, bandwidth, integration time, and weighting to justify a fair comparison. This verdict is not a strike against the ledger figure. It marks a limit on what this pass could check.

Pattern: Every strong match came from a paper that states all four parameters explicitly: frequency, bandwidth, time, and weighting. Every divergence or non-verifiable case was missing at least one parameter. The weighting or taper scheme was missing most often. The calculator needs this parameter, but deep and ultra-deep tiers rarely state it in prose. It usually appears in a table or figure that retrieval did not fully capture.

Not run: This pass excluded galaxy-count and population-model figures, including A-04, from calculator verification. These figures depend on an assumed mass function, not on raw sensitivity.
