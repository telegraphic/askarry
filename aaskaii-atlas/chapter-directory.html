Method & provenance

Each title links to https://www.skao.int/sites/default/files/documents/<paper-id>.pdf on SKAO's public site. Askarry uses this same identifier internally as the PDF filename. We confirmed this against SKAO's own AASKAII listing page for a sample of entries. If a link returns a 404 error, the chapter was likely renumbered or withdrawn since ingestion. In that case, search the title directly on SKAO's listing page.
