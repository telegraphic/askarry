Method & provenance

This page copies five components verbatim from askarry's rag/ingestion.py::find_acronym_candidates: the inline-definition regex, British/American spelling folding, plural stripping, near-synonym clustering, and the category classifier. It runs these components against a direct export of the app's ChromaDB chroma.sqlite3 store, filtered to doc_source = aaskaii. That export covers the same 10,678 indexed chunks across 206 source PDFs that the live Acronyms tab scans for the AASKAII (2026) report.

This table reflects the app's data as it stood on 2026-08-23. It is not a live connection to the database. Re-run the export after ingesting new papers to refresh the table. Keep this file in the same folder as the rest of the atlas, or the links above will break. The paper list itself lives in the Chapter Directory.
