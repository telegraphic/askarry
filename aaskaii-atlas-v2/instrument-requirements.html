Instrument Requirements

The register collects the concrete demands that AASKAII chapters place on the telescopes. These include sensitivity, angular resolution, field of view or survey area, frequency, observing time and the array stage at which each becomes possible. Every row carries the sentence it was taken from, and that sentence was matched against its chapter before the row was admitted.

How the register was built

One agent read each of the seven book sections. It searched every chapter for stated requirements and copied the sentence that states each one. A script then looked for every quoted sentence in the chapter it names. A row survives only if the sentence appears there word for word. When a quotation runs across two of the indexed passages of a chapter, each of its sentences must appear. All 682 quotations that the agents returned passed this test, so no row had to be dropped. A field is left empty when the chapter does not state a value. An empty cell therefore records the chapter's silence, not a gap in the extraction.

The register is a sample of what the book asks for, not a complete specification. It favours chapters that state their requirements in numbers. The sensitivity page reruns the rows that give enough parameters through the SKAO calculator, and the capability page asks which array stage can deliver each one. For the frequency chart, a parser in scripts/build_atlas_data.py reads each row's frequency field. It recognises stated frequencies, wavelengths and band names, and it ignores bandwidths. Rows whose field names no frequency are left off the chart, but they stay in the register.
