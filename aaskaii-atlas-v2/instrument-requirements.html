Instrument Requirements

The register collects the concrete demands that AASKAII chapters place on the telescopes: sensitivity, angular resolution, field of view or survey area, frequency, observing time and the array stage at which each becomes possible. Every row carries the sentence it was taken from, and every sentence has been matched against the chapter it is attributed to before it was admitted.

How the register was built

One agent read each of the seven book sections, searching every chapter for stated requirements and copying the sentence that states each one. A script then looked for every quoted sentence in the chapter it names; a row survives only if the sentence is there verbatim, or, when a quotation runs across two of the passages into which the chapter was indexed, if each of its sentences is. Every one of the 682 quotations the agents returned passed this test, so no row had to be dropped. Fields are left empty when the chapter does not state a value, so an empty cell records the chapter's silence rather than a gap in the extraction.

The register is therefore a sample of what the book asks for, weighted toward chapters that state their requirements in numbers; it is not a complete specification. The sensitivity page reruns the rows that give enough parameters through the SKAO calculator, and the capability page asks which array stage can deliver each one.
