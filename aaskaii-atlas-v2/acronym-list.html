Acronyms

This list holds every acronym that an AASKAII chapter defines in the form "Full Name (ABC)". For each one it gives the most common expansion, the number of times the acronym occurs and the number of chapters that use it. The same extractor that expands acronyms in search produces the list, so it reflects what the retrieval system itself knows.

All acronyms

The categories come from a keyword rule applied to each expansion (rag/ingestion.py::classify_acronym). They are meant to help you browse, not to form a taxonomy. The rule matches whole words only, so it does not mistake "Field-Programmable Gate Array" for an organisation because it contains "program".
