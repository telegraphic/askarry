Every acronym that an AASKAII chapter defines in the form "Full Name (ABC)" appears below, with its most common expansion, the number of times it occurs and the number of chapters that use it. The list is produced by the same extractor that powers acronym expansion in search, so it reflects what the retrieval system itself knows.
