Observing-Mode Map

The map counts how many chapters in each of the book's seven sections name each of fifteen observing modes. It shows how widely the science case relies on a mode. It does not show competition for telescope time, because a mode can be named often yet need few hours; the time-demand page measures that competition from the hours that chapters request.

Chapters per section

Each cell gives the number of chapters in a section that name the mode at least twice. Hover over a cell to see how many chapters the section has, or switch to percentages to compare sections of different sizes.

Section by section

Each summary describes what one book section asks of the telescopes. The agent that read the section wrote it from the chapters it searched.

Which chapters

Open an entry to see the chapters behind each count, grouped by section. Each chapter ID opens its row in the chapter directory, and the PDF tag beside it opens the chapter itself.

Search terms

How to read the counts

A chapter counts toward a mode when the mode's search terms appear in it at least twice. This threshold removes passing mentions and institutional affiliations, but it keeps chapters that discuss the mode in earnest. The search terms for each mode are listed above. If you doubt a count, you can therefore see exactly what was matched and rerun the search with keyword_coverage_tool.
